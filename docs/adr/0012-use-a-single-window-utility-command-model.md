# Use a single-window utility command model

Skill Deck is a single-window management utility rather than a document app: it has no New Window/New Document command, keeps Settings as a modal utility surface in the main window, and assigns Find & Install to `Cmd/Ctrl+Shift+I` instead of overloading `Cmd/Ctrl+N`. This favors honest, stable desktop command semantics and a smaller cross-platform window model over a more elaborate macOS-style multi-window structure.
